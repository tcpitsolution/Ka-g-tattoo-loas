# Ka-G Tattoo Studio — Website v2

A responsive React + Vite landing page with a completely refreshed editorial palette: warm paper, oxblood, rust, and ink. It includes an inspiration gallery with lightbox controls, responsive navigation, a WhatsApp enquiry form, Instagram, phone and directions links, SEO metadata, and TCP IT Solution footer credit.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Netlify
- Build command: `npm run build`
- Publish directory: `dist`

## Notes
- WhatsApp contact uses `856207667520` and opens a pre-filled message. Form data is not stored or submitted to a backend. The studio must confirm appointment availability.
- Gallery images are remote Unsplash-hosted reference imagery, not claims of verified work by the studio. Replace with studio-approved photos before launch.
- Business hours are displayed only as “Closes at 8:00 PM”, as provided.
